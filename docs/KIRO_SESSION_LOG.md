## HAND-FIX (rebuild agent, NOT Kiro) — debit/credit gating, 50/50

- Time: 2026-11-06 ~14:05 UTC. Logged here, NOT claimed as Kiro work.
- Cause diagnosed by the rebuild agent with a direct node check:
  `detectColumns` returned `amountCol: 2, debitCol: 2, creditCol: 3` for the
  Debit/Credit file, and for plain Amount files the shape-scored debitCol /
  creditCol were also non-null, so Session 08's clearing rule broke them.
- Fix (in `engine.js`, `detectColumns`, marked with a HAND-FIX comment):
  debitCol/creditCol only count as detected when a header actually names
  them (`/debit|withdrawal|out/i`, `/credit|deposit|in/i`); otherwise they
  are set to null. The amountCol-clearing rule then only fires for real
  debit/credit files.

  **50 tests, 50 pass, 0 fail.** `grep -c "fetch(" engine.js` = 0.
